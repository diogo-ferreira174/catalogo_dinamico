# 📚 Catálogo Dinâmico

Um catálogo de produtos desenvolvido com **HTML, CSS e JavaScript**, permitindo a exibição dinâmica de itens de forma organizada e intuitiva. O projeto foi criado com foco em praticar manipulação do DOM, estruturas de dados e desenvolvimento Front-End.

---

## 🚀 Funcionalidades

* 📦 Exibição dinâmica de produtos
* 🔍 Organização visual dos itens
* 🎨 Interface simples e responsiva
* ⚡ Atualização fácil dos dados
* 📱 Compatível com diferentes dispositivos

---

<div align="center">

## ▶️ Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/diogo-ferreira174/catalogo_dinamico.git
```

### 2. Acesse a pasta do projeto

```bash
cd catalogo_dinamico
```

### 3. Execute

Abra o arquivo `index.html` em qualquer navegador.
